
## 決め事

**2026-09-09、代表の「ありきたり」の指摘でデザインを一から組み直した。**
考えは1つ。**空調は、目に見えない空気を設計する仕事。だからサイトを、見えないものを見えるようにする装置にする。**

- **地は二つだけ。**墨 `#080d0e` と 生成り `#f5f1e7`。この二つを章ごとに大きく切り替える
- **色は「温度」しか使わない。**冷 `#2f7275`（旧サイトの `#1a6969` を深めた）／温 `#b8663a`（旧 `#ccbb89` の代わり）。
  **この2色は温度計の両端**という意味を持たせてある。旧サイトの色は捨てず、冷たい側へ寄せて残した
- **差し色は 線 と 数字 にだけ。**面で塗らない。濃い地の上だけ白ベタを許す
- **角は落とさない（0px）。影は使わない。**境は罫線だけで引く
- **見出しは明朝**（Noto Serif JP 400）。**級数の差が主役** … 見出し 84px ／ ラベル 10px
- 欧文は Jost 300。**頭の並びには欧文ラベルを出さない**（8項目あると潰れるため。足には出す）

### 動き — 1画面に1つ

**2026-09-10、代表の指示で「スクロールに応じて動く背景」ほかを足した。**
**JS は増やしていない。全部 CSS の `animation-timeline`（`scroll()` と `view()`）で書いてある。**

| どこ | 何 | 実装 |
|---|---|---|
| **地（節ぜんぶ）** | **温度の場（等温線）が、読み進めるあいだ ゆっくり流れる** | `field.svg` を `mask` に使い、色は節が持つ。`view()` で上下へ ±5.5% |
| 左端 | **温度計が下から満ちる。**目盛り付き | `scroll(root)` ＋ `clip-path` |
| 頭 | 膜の色が 冷 → 温 へ寄る（明るくはしない） | `@property --hd` ＋ `scroll(root)` |
| 冒頭 | 読み込みのずらし（既存）／読み進めると 写真が沈み 言葉が先に去る | `scroll(root)` `0 → 100svh` |
| 節の入り | 見出しの足元の罫が 左から伸びる | `view()` `entry 8% → cover 26%` |
| 夜明け・日暮れ | **帯を通るあいだに 日が昇る／沈む** | 光の玉を `view()` で上下。**地のグラデ本体は動かさない**（継ぎ目が出る） |
| 数字の帯 | 数字が読み上がる（既存）／写真がゆっくり寄る | `view()` |
| **仕組みの断面図** | **空気の流れが引かれ、室外機が回り、ドレンが流れる** | `pathLength="1"` ＋ `stroke-dashoffset`。`view()` |
| 施工実例 | 枠は動かさず、枠の中で写真が動く | `object-position` を `view()` で。**`transform` だと `:hover` と食い合う** |

**⚠️ 動かした先の「止まった絵」で成立させてある。**等温線は敷いたまま、断面図は引き終わった形、罫は伸びきった形。

**⚠️ この Mac は「視差効果を減らす」が ON**（2026-09-10 実測 `reduceMotion 1`）。
**ヘッドレスの Chrome もその設定を継ぐ。**`--force-prefers-reduced-motion` を外しても止まったままなので、
**動く状態を見るには、CSS の判定を入れ替えた写しを作って撮る**（`prefers-reduced-motion:no-preference` ↔ `:reduce`）。
**代表の画面では、入れた動きは全部 止まって見える。**

## 実測（2026-09-10 動きを足したあと）

**目視で終わらせていない。全17ページを機械で測った。**

- 17ページ・HTML 合計 249KB／CSS 57KB／JS 4KB／画像 3.00MB（81本）
- **地の等温線 `field.svg` は 9KB。**marching squares で描いて、ほぼ一直線の点を間引いてある（間引かないと 58KB）
- **幅 375 / 1280 / 1660px … 17ページで 横はみ出し0・幅超え要素0**
- 触れる大きさ30px未満は各ページ1つ。**「本文へ移動」の読み上げ用リンク（1×1px）だけ**なので直さない
- 点検 赤0・黄0。`slop.py` 赤0（黄3はどれも前からの書体の指摘）

**⚠️ 動きを足すときに実測で見つけて直した穴が4つ。**

1. **地の面が 左右へ4%はみ出して、幅375pxで横スクロールが15px出た。**
   `overflow-x:clip` で止めた。**`hidden` は使えない** … スクロール容器になって、中の `animation-timeline:view()` が当たらなくなる
2. **節の子に `position:relative` を配って、`.cta__ph` の写真が版面へ流れ出した。**
   節を `isolation:isolate` にして、地を `z-index:-1` へ沈める形に変えた
3. **`.sec--tight` は下層で単独で使われていて（`.sec` が付いていない）、6節が地無しで抜けていた**
4. **温度計の「まだ読んでいない側」を白の半透明にしたら、明るい節で消えた。**
   温度の色を彩度だけ落とした不透明の帯にした

**⚠️ 刷新のときに実測で見つけて直した穴が4つ。**
