## ⚠️ 検索には出さない

`noindex` と `robots.txt` の `Disallow: /` が入っている。**外さないこと。**
現行サイトが生きているあいだに検索へ載せると、同じ本文が2か所に出て現行サイトの評価を削る。
外すのは本番として公開する日で、それは代表が決めること。

## 組み立て

**HTML は手で書かない。`_build/` から作る。**

```bash
cd ~/repos/personright-demo
python3 _build/build.py    # 17ページを書き出す
python3 _build/check.py    # 点検（赤0・黄0が通常）
```

| ファイル | 何 |
|---|---|
| `_build/common.py` | 頭・ヘッダー・フッター・お問い合わせの帯・構造化データ。**全ページ共通はここだけ** |
| `_build/p_top.py` | トップ |
| `_build/p_ac.py` | 業務用エアコン `/ac/` |
| `_build/p_office.py` | 通信機器 `/office-tech/` |
| `_build/p_company.py` | 会社案内 `/company/` |
| `_build/p_recruit.py` | 採用情報 `/recruit/` と求人4本 |
| `_build/p_reviews.py` | お客様の声 `/reviews/` と個票4本 |
| `_build/p_misc.py` | お問い合わせ・送信完了・プライバシーポリシー |
| `_build/check.py` | h1・見出しの階層・alt・リンク切れ・画像の実在・JSON-LD・重さ |

**CSS と JS の URL には中身から作った版番号が付く**（`style.css?v=…`）。
中身を変えれば URL も変わるので、古いものがキャッシュに残らない。

## 決め事

- **主色 `#1a6969`・差し色 `#ccbb89` は現行サイトから引き継いだ。**
- **見出しは明朝**（Noto Serif JP 600 を1ウェイトだけ）。欧文は Jost（現行の futura-pt の代わり）
- **差し色は線と数字にだけ。面で塗らない。**濃い地の上だけ白ベタを許す
- **角丸は2px。影は使わず罫線。**
- **動きは1画面に1つ。**ヒーローの気流（canvas）／見出し下の線が伸びる（`animation-timeline: view()`）／ページ切り替え（`@view-transition`）
- **「視差効果を減らす」が入っていると全部止まる。止めた絵で成立するように作ってある。**
