## 組み立て

**HTML は手で書かない。`_build/` から作る。**

```bash
cd ~/repos/personright-demo
python3 _build/build.py    # 17ページを書き出す
python3 _build/check.py    # 点検（赤0・黄0が通常）
```

## 決め事

**2026-09-09、代表の「ありきたり」の指摘でデザインを一から組み直した。**
考えは1つ。**空調は、目に見えない空気を設計する仕事。だからサイトを、見えないものを見えるようにする装置にする。**

- **地は二つだけ。**墨 `#080d0e` と 生成り `#f5f1e7`。この二つを章ごとに大きく切り替える
- **色は「温度」しか使わない。**冷 `#2f7275`（旧サイトの `#1a6969` を深めた）／温 `#b8663a`（旧 `#ccbb89` の代わり）。
  **この2色は温度計の両端**という意味を持たせてある。旧サイトの色は捨てず、冷たい側へ寄せて残した
- **差し色は 線 と 数字 にだけ。**面で塗らない。濃い地の上だけ白ベタを許す
- **角は落とさない（0px）。影は使わない。**境は罫線だけで引く
- **見出しは明朝**（Noto Serif JP 400）。**級数の差が主役** … 見出し 84px ／ ラベル 10px
- 欧文は Jost 300。**頭の並びには欧文ラベルを出さない**（8項目あると潰れるため。足には出す）

### 動き — 1画面に1つ

| どこ | 何 | 実装 |
|---|---|---|
| 冒頭 | **等温線**（このサイトの署名） | canvas。marching squares で温度場の等高線を13本引く。**粒子を飛ばさないのは、止めた1枚で成立させるため** |
| 節の入り | 見出し下の罫が伸びる | `animation-timeline: view()` |
| 頁の移動 | 1枚に見せる | `@view-transition` |
| 仕組みの節 | **断面図** | インラインSVG。写真で撮れないものは自分で描く |

**⚠️ この Mac は「視差効果を減らす」が ON。**実測でも `prefers-reduced-motion: reduce` が真だった。
**上の screenshot は全部その静止状態のもの。**止めた絵で成立している。
